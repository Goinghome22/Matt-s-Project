# Module: Python 2 — Budget Calculator

Track trip costs via CLI input or a simple GUI.

## CLI
```bash
python3 vacation_budget.py
```
- Prompts for flight, hotel, food, and transportation
- Prints totals and budget result

## GUI (Tkinter)
```bash
python3 "import tkinter as tk.py"
```
- Enter costs in fields and click Calculate
- Shows a popup summary and prints per-category breakdown to terminal

## Outcomes
- Practice input handling, basic arithmetic, and simple GUI construction.
