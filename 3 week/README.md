# 3-Week Track

A short, intensive program focused on core foundations, practical tooling, and security fundamentals.

## Structure

- Semester 1: Foundations and Design
  - version_control_1
  - prompt_engineering_1
  - figma_1
  - design_1
- Semester 2: Security, Python, and SOC
  - cybersecurity_basics_1
  - cyber_threats_and_vulnerabilities_1
  - python_1
  - security_operations_center_1

## Highlights

- Git and collaboration workflows
- Prompt engineering for LLMs
- Figma for UI/UX ideation
- Security concepts, common threats, and basic scanning
- Python scripting and a simple File Integrity Monitor
- SOC artifacts (scan outputs, risk reports)

## How to Navigate

- Each module folder contains its artifacts (PDFs, scans, scripts, designs).
- See each semester folder `README.md` for specifics, setup, and how to run scripts where applicable.
