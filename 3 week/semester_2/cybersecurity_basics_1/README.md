# Module: Cybersecurity Basics

Foundational security concepts and documentation.

## Contents
- Risk Management Report.pdf
- Risk Register.xlsx
- 🔍 Vulnerability Scan Report.pdf
- juice_scan.txt
- Matt Rich Cybersecurity Project.pdf

## How to Use
1. Read the Risk Management Report to understand approach and context
2. Review Risk Register.xlsx to see prioritization and ownership
3. Skim the Vulnerability Scan Report and `juice_scan.txt` for technical findings
4. Tie findings back to risk and remediation planning

## Outcomes
- Understand core security documents and how technical findings translate into risk.
