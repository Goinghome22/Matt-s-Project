# 3-Week • Semester 1 — Foundations and Design

This semester establishes practical foundations across version control, AI prompting, and product design.

## Modules and Materials

- Version Control (`version_control_1`)
  - Focus: Git basics, branching, commits, GitHub workflows.
  - Materials: PDF(s) and design artifacts to support exercises.

- Prompt Engineering (`prompt_engineering_1`)
  - Focus: Prompt patterns, structuring inputs, evaluation, iterative refinement.
  - Materials: PDF(s) for guided practice.

- Figma (`figma_1`)
  - Focus: Low/high-fidelity ideation and component thinking.
  - Materials: `.fig` file(s) you can open in Figma Desktop or Figma Web.
  - Tip: Duplicate the file into your own Figma workspace for editing.

- Design (`design_1`)
  - Focus: UX heuristics, layout, typography, and accessibility awareness.
  - Materials: PDFs and example assets.

## How to Use

- Open PDFs for context and reading assignments.
- For Figma files: open with Figma (desktop or web). If the file is large, allow time for assets to load.
- Use Git locally to practice commands from the materials:
  - Initialize a playground repo, branch, commit, and open a PR on GitHub.

## Outcomes

- You will be comfortable with Git basics, able to structure effective prompts for LLMs, and translate ideas into simple designs.
