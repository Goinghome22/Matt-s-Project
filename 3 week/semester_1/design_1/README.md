# Module: Design Fundamentals

Practice UX heuristics and systematized visual design.

## Topics
- Usability heuristics and mental models
- Layout systems and rhythm
- Typography, color, contrast, and hierarchy
- Accessibility considerations

## Activities
- Audit a screen against 3–5 usability heuristics
- Redesign to improve clarity and hierarchy
- Document component rules (spacing, states, errors)

## Outcomes
- Create designs that are readable, consistent, and accessible. 

## Assessment / Rubric
- ✅ Heuristic evaluation documented with findings
- ✅ Revised design improves clarity and task success
- ✅ Consistent spacing, typography, and states

## Next Steps
- Build an accessibility checklist for future work
- Create before/after comparisons with rationale
- Validate with a quick user test or heuristic review
