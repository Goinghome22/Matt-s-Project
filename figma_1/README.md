# Module: Figma

Explore ideation, layout, and components using Figma.

## Open the File
- Open the `.fig` file in Figma Desktop or the Web app
- If needed, import or duplicate into your own workspace to edit

## Suggested Tasks
- Create low-fidelity wireframes for a key screen
- Convert wireframes to mid/high-fidelity designs
- Use components and variants for reusable UI elements
- Apply layout grids, spacing, and typographic scale

## Tips
- Name frames and layers clearly
- Use auto-layout for flexible, consistent spacing
- Consider accessibility (color contrast, font size)

## Outcomes
- Turn ideas into clear, shareable design artifacts.
